# 【Python 版本】Python ≥ 3.12
#   ⚠️ 口径提示：`01-实施步骤与本地部署.md` §3 正文写的是 `brew install python@3.11`
#      并称「MinerU 与依赖对 3.11 兼容性最好」。本文件按「Python ≥ 3.12」口径编写，
#      两者的差异已在交付说明中列为文档内部矛盾，落地前需确认；无论如何请固定
#      **同一个**解释器创建 venv，不要让 3.11/3.12 混用同一份 site-packages。
#
# 【Apple Silicon 注意】faiss-cpu 在 arm64 上走 Accelerate 框架（Accelerate.framework
#   提供的 BLAS/LAPACK），无需手工编译：
#     · 只装 `faiss-cpu`，**不要装 `faiss-gpu`**（本机无 NVIDIA 卡，且官方未提供
#       macOS arm64 的 GPU 轮子，装了会拖入 CUDA 依赖并安装失败）；
#     · 也不要用 conda 的 `faiss-cpu`，混用 conda 与 venv 会让 Accelerate 链接错乱。
#
# 【版本口径】
#   · 标 `[01 §3]` 的行 = `01` §3 原文写了版本，此处照抄（原文用通配，保持通配形式）；
#   · 标 `待实测确认` 的行 = 文档未给版本，此处给一个可用稳定版本，
#     **必须在 POC 首周用 `pip install` 实测后回填确定值**（对应 `00` §11 的实测项）。
#   · 所有版本用 `==` 锁定；升级请成组升级并重跑 deploy/scripts/smoke.sh。
#
# 【分组】Web / 数据 / 检索 / 云端模型 / 解析 / 钉钉 / 工具与日志 / 测试
# =============================================================================

# ---- 解析（MinerU + Office 文档）----
# [实测修订 2026-09-27] MinerU **不装进应用 venv**，改为独立 venv + CLI 子进程调用。
#   为什么改：
#   ① 本仓库的解析器是 **子进程** 调用 `mineru -p … -o …`（见 ekbs/ingest/parser.py），
#      不 `import mineru`，因此应用 venv 里没有它也能工作；
#   ② 装进来会把 torch/transformers/ultralytics 等约 2.0 GB 拖进生产 venv
#      （16 GB 机器上不划算），且实测会在 pip 解析它的依赖树回溯时
#      去构建 colorlog 的 sdist 而**整单失败**（colorlog 的 setup.py 有循环导入）。
#   安装方式（与 01 §4 一致）：
#       python3.12 -m venv /opt/ekbs/mineru-venv
#       /opt/ekbs/mineru-venv/bin/pip install 'mineru[core]==2.1.10'
#       export MINERU_MODEL_SOURCE=modelscope        # 实测 HuggingFace 不可达
#       export EKBS_MINERU_BIN=/opt/ekbs/mineru-venv/bin/mineru
#   model 权重首次运行下载 2–3 GB（00 §11 的 M1）。
