# EKBS 公开基准评测 · 一页纸结论（2026-10-25）

> 完整数据、口径与复现：`docs/公开基准评测报告-2026-10-25.md`。
> 范围：仅公开中文 RAG 基准与公开模型，不使用部门自有数据。

## 1. 核心指标

| 维度 | 指标 | 结果 | 判断 |
|---|---|---|---|
| 检索命中 | RGB Hit@10 / MRR | 0.961 / 0.857 | 好 |
| 检索覆盖 | RGB Recall@10 / nDCG@10 | 0.624 / 0.638 | 一般（每题约 6 篇 gold） |
| 答案准确率 | RGB 官方 checkanswer | **91.1%** | 好 |
| 回答忠实度 | RAGAS Faithfulness | 0.937 | 好 |
| 上下文质量 | RAGAS Context Recall / Precision | 0.947 / 0.714 | 召回好、精度一般 |
| 向量模型 | DuRetrieval nDCG@10 / Recall@100 | 0.870 / 0.966 | 好，不是瓶颈 |
| 拒答 | RGB 官方负例-only 拒答 | **7.6%** | **最大短板** |
| 跨语料 | CRUD-RAG 全量 83,814 篇 正确率 | 33.1% | 明显退化 |

## 2. 三个结论

1. **检索与忠实度达标，向量模型不是瓶颈**：RGB 的 Hit@10 0.961、RAGAS F 0.937、DuRetrieval nDCG@10 0.870。
2. **拒答是当前最大短板**：官方负例口径仅 7.6%；提高到阈值 0.90 仍放行 40% 负例，阈值不可救，需要回答侧语义核验。
3. **RGB 结论不能外推到 CRUD-RAG**：全量口径下证据覆盖 0.376、答案正确率 33.1%（长文档、多事实点）。

## 3. 已定的改进：回答后置核验门禁（默认关闭）

- 判官：**`deepseek-flash` + `reasoning_effort: high`**（横评优于 qwen-max、MiniMax 和旧别名 reasoner）；
- 只对 **rerank 0.65–0.85 的边界题**调用，判官认为资料不支持 → 拒答；
- RGB 真实代码路径回归：负例-only 拒答 **19.2% → 42.0%**，可答误拒仅 **+0.5pp**（91.1%→91.4% 准确率）；
- 生产默认 `enabled: false`，灰度步骤见 `deploy/RUNBOOK-回答核验灰度.md`。

## 4. 建议下一步（按 ROI）

1. 生产灰度 `answer_verify`（先只开问答 API，观察误拒/失败率/延迟，再决定是否扩到钉钉）；
2. 待 CRUD 全量 80k 跑完，复核"全量 vs 收窄"与"门禁 vs 无门禁"两组数字；
3. 质量改进：检索宽度/融合权重按语料校准、长文档证据聚合（已证明切块不是瓶颈，瓶颈在文档排序）；
4. 若对外报 CRUD 分数，必须用全量 80k 口径，收窄口径数字只用于内部回归。

## 5. 边界与 caveat

- RAGAS 为 30 题分层抽样，不是全量；CRUD 当前主结论基于"源文档 + 1.36 万干扰文档"的收窄口径；
- CRUD 答案判分是自建 DeepSeek 判官，已与 QuestEval-lite 对照（0.265 vs 0.263），结论一致；
- 未做人工评估；门禁的线上误拒率需灰度验证。
